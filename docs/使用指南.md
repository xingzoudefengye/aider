# 使用指南

日常只需记住三个命令：

| 操作 | 命令 | 在哪里输入 |
| --- | --- | --- |
| 管理模型、查看会话 | `aider admin` | PowerShell 或其他系统终端 |
| 开始编程 | `aider` | 系统终端，先进入你的项目目录 |
| 切换模型 | `/model` | Aider 会话输入框 |

## 1. 首次安装

需要 Python 3.10–3.14 和 Git。本分支尚未独立发布到 PyPI，下面直接安装本仓库的 `main` 分支。

### Windows

打开 PowerShell，先安装 pipx 并配置命令路径（只做一次）：

```powershell
python -m pip install --user pipx
python -m pipx ensurepath --prepend
```

**关闭终端并重新打开**，然后安装：

```powershell
python -m pipx install "git+https://github.com/xingzoudefengye/aider.git@main"
aider --version
```

看到版本号就安装成功。之后可以在任意项目目录直接运行 `aider`，无需激活虚拟环境。

### macOS / Linux

先通过系统包管理器安装 pipx，例如 macOS 使用 `brew install pipx`，Ubuntu 使用 `sudo apt install pipx`。

```bash
pipx ensurepath
```

重新打开终端后：

```bash
pipx install "git+https://github.com/xingzoudefengye/aider.git@main"
aider --version
```

其他系统的 pipx 安装方式见 [pipx 官方安装说明](https://pipx.pypa.io/latest/how-to/install-pipx.html)。

<details>
<summary>已经克隆源码，想直接使用本地代码</summary>

在克隆的 Aider 目录中，使用当前 Python 环境安装：

```bash
python -m pip install -e .
```

如果安装在虚拟环境里，先激活该环境再运行 `aider`。这适合开发者；普通用户按上面的 pipx 方式安装即可。

</details>

## 2. 配置模型

先进入**你要编程的项目目录**，再打开管理页。例如 Windows：

```powershell
cd E:\Projects\my-project
aider admin
```

浏览器会自动打开；终端也会打印管理页地址。**端口自动分配，不需要指定。**

在「模型设置」中：

1. 点击「添加模型」。
2. 填写服务商提供的 **模型 ID、Base URL、API Key**。
3. 选择对应的 **API 协议**。
4. 勾选「设为默认模型」，点击「保存」。
5. 点击「测试连接」，确认配置可用。

| API 协议 | 对应接口 |
| --- | --- |
| OpenAI Chat Completions | `/chat/completions` |
| OpenAI Responses | `/responses` |
| Anthropic Messages | `/messages` |

协议以服务商提供的接口为准。Base URL 填接口的基础地址：OpenAI 兼容接口通常类似 `https://api.example.com/v1`，Anthropic 通常类似 `https://api.example.com`。无需追加 `/chat/completions` 等操作路径。

供应商名称会自动生成。点击名称旁的编辑图标，可以修改名称、URL 和 Key。
在已有供应商下点击「添加模型（当前供应商）」时，URL 和 Key 自动继承，只需填写模型 ID、选择协议。

「更多设置」默认折叠，可配置上下文窗口、图片输入和思考强度。初始值为 **512000 tokens、支持图片、中等思考强度**；按模型实际能力调整。

模型配置保存在当前项目的 `.aider.providers.json` 中。**管理页和 CLI 要在同一个项目目录启动。** 配置文件可能含 API Key，不要提交到公开仓库。

## 3. 启动 CLI

管理页配置完成后，可以在原终端按 `Ctrl+C` 关闭管理页，再输入：

```bash
aider
```

也可以保留管理页，在另一个终端进入同一项目目录后运行 `aider`。

新会话会使用管理页设置的默认模型。进入后直接输入需求；需要修改文件时，用 `/add` 加入文件，例如：

```text
/add src/main.py
帮我检查这个文件的错误，并修复
```

用 `/ask 问题` 进行问答，用 `/help` 查看命令，用 `/exit` 退出。

### 发送截图或图片

1. 复制截图或图片，在 Aider 输入框按 `Ctrl+V`。
2. 输入框出现 `[image #1]` 后，继续输入要问的问题，按回车发送。
3. 可重复粘贴多张图片，每张独立编号，不会覆盖上一张。

如果终端没有转发图片粘贴事件，输入 `/paste` 并按回车，图片标记会出现在下一次输入框中。粘贴只准备草稿，不会立即请求模型；普通文字粘贴保持原样。

也可以用 `/add "图片路径"` 添加磁盘上的图片。添加的图片作为当前会话参考文件保留，可用 `/drop clipboard_image_1.png` 等命令移除。模型明确关闭图片支持时，请先用 `/model` 切换或在管理页「更多设置」中启用。

## 4. 在会话里切换模型

在 Aider 输入框中输入：

```text
/model
```

按回车打开模型列表：

- `↑` / `↓`：选择已配置并启用的模型。
- `Enter`：确认切换。
- `Esc`：取消。

面板顶部显示当前模型，列表显示供应商和模型 ID。切换后继续当前对话，无需退出重启。

模型选择会保存到当前聊天历史对应的模型记录中。恢复带有该记录的会话时，沿用上次选择；模型已删除或停用时，会提示并使用当前默认模型。

## 5. 切换工作模式（Shift+Tab）

在会话输入框按 `Shift+Tab`，会按顺序循环切换工作模式，切换后立即生效并打印当前模式：

| 顺序 | 模式 | 说明 |
| --- | --- | --- |
| 1 | 问答（ask） | 只回答问题，不修改任何文件 |
| 2 | 计划（plan） | 先用计划模型规划，再由编辑器落地改动 |
| 3 | 编辑（edit） | 直接按当前模型的最佳编辑格式修改代码 |
| 4 | 自动（auto） | 自动确认所有交互，直接规划并落地改动 |

除这四种，还可以用 `/chat-mode 名称` 切换到 `context`（自动识别需要修改的文件）、`help`，以及 `diff`、`whole`、`udiff` 等编辑格式。输入 `/chat-mode` 回车会列出所有可选模式。Aider 原生的 `architect`、`code` 仍可作为别名输入。

> 自动模式会把确认提示（例如「Edit the files?」、是否修复 lint）全部按 Yes 处理，适合放手让它连续干活；切回其他模式会恢复你启动时的确认设置。

## 6. 查看和恢复会话

在同一项目目录运行 `aider admin`，点击左侧「会话管理」：

1. 用搜索框查找会话，下拉框可选择全部、按项目、按标题或归档。
2. 点击列表中的会话，右侧查看历史内容。
3. 点击标题旁的编辑图标修改标题；消息旁的复制按钮可复制正文。
4. 「更多操作」中可以复制会话 ID、复制已加载对话或归档会话。

**继续旧会话：点击「复制恢复命令」，粘贴到系统终端并执行。** 点击复制时，管理页会准备对应会话的独立历史文件。

命令类似这样，无需自己拼接：

```powershell
aider --restore-chat-history --chat-history-file 'E:\Projects\my-project\.aider.session-history\31.md'
```

执行前先进入对应项目目录。恢复后会显示历史对话和当前模型等信息，再直接发消息继续。

列表中的删除按钮直接删除会话，不弹确认框。

## 7. 常用命令

以下命令都在 **Aider 会话输入框** 中输入：

| 命令 | 用途 |
| --- | --- |
| `/model` | 用方向键选择模型，查看当前模型 |
| `/add 文件路径` | 加入需要修改的文件 |
| `/paste` | 从剪贴板粘贴图片或文字到草稿 |
| `/drop 文件名` | 移除当前会话中的文件或图片 |
| `/ask 问题` | 问答模式 |
| `/chat-mode 名称` | 切换工作模式，等效于按 `Shift+Tab` |
| `/cache` | 查看会话缓存统计 |
| `/compact status` | 查看自动交接阈值、交接次数和史书状态 |
| `/compact` | 手动进行本地交接压缩 |
| `/memory` | 查看当前项目记忆 |
| `/memory add 内容` | 手动保存项目记忆 |
| `/memory search 关键词` | 搜索项目长期记忆 |
| `/memory reload` | 重新加载项目记忆 |
| `/help` | 查看更多命令 |
| `/exit` | 退出 |

自动交接通常在上下文达到 **75%** 时触发，同时考虑输出预留。项目自动记忆保存在 `.ai/`，跨会话检索及时间衰减自动运行，无需额外启动服务。

## 常见问题

### 输入 `aider` 提示「命令无法识别」

如果按 pipx 安装，运行下面的命令后，关闭并重新打开终端：

```bash
python -m pipx ensurepath --prepend
```

如果按源码方式安装，可以先用 `python -m aider` 或 `python -m aider admin` 启动；虚拟环境安装需要先激活环境。

### 输入 `admin` 没有打开网页

`aider admin` 是**系统终端命令**，不是会话命令。先用 `/exit` 退出 Aider，再在 PowerShell 等终端输入 `aider admin`。

### 默认模型没有生效，或者会话列表是空的

确认管理页和 CLI 的项目目录相同。恢复会话时，已保存的会话模型优先于 Web 默认模型。

### 如何更新

按 pipx 安装的用户，在系统终端运行：

```bash
pipx upgrade aider-chat
```

本分支目前仍使用 `aider-chat` 包名，终端命令是 `aider`。已有上游版本时，可在 Windows 用 `Get-Command aider -All` 检查实际运行的是哪个安装位置。
